## How to Run the Application

1. Install Python.
2. Install the required packages:

   pip install flask python-dotenv

3. Create a .env file in the project folder
   containing a unique SECRET_KEY.
   This file should not be uploaded to GitHub.

4. Make sure SecureProgramming.db is in
   the project folder.

5. Run the application:

   python app.py

6. Open http://127.0.0.1:5000 in a browser.

## Security Features

- Secure password hashing
- Role-based access control
- Administrator user role management
- Audit logging
- Parameterized database queries
- Secret key stored in an environment file
- Flask debug mode disabled
